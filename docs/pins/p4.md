## Notes per pin

- **Database and product secrets are not in this file or in any committed file.** Each run generates them and keeps them in `.harness/<product>/secrets.json` (mode 0600). `CLAUDE.md` forbids committed passwords.
- **RAM budget:** 14336 MiB (14 GiB) of a 16 GB runner. The committed value is `RAM_BUDGET_MIB` in `src/adapters/p4-ram.ts`. Measured numbers are in `evidence/ram-probe.json` (CI artifact `ram-probe`); see the plan's section 18.

- **Twenty (Q6):** `docker/twenty.compose.yml` is not changed and no Twenty default is changed. The digest above is the observed digest of `v2.44.0` from `docker pull`, recorded here only.
- **Nextcloud official app (Q3):** an official Nextcloud-published MCP app was checked on apps.nextcloud.com and is **UNVERIFIED**: the appstore was unreachable from the session, so no official app could be confirmed or ruled out. The third-party `cbcoutinho` server is used.
- **Outline (Q1):** licence BSL 1.1, accepted for non-production self-hosted QA use. Reason recorded in ADR 0006.
- **Mattermost MCP (Q2):** development-only standalone binary, built from the pinned commit and bound to 127.0.0.1. The Enterprise-only embedded endpoint is not used.

- **Agent hosts (ADR 0007).** Image licences above come from the images. Upstream GitHub release notes were not readable in the session (UNVERIFIED). MongoDB SSPL is accepted for local QA only (review answer 0.10).
- **Agent-host network (review answer 0.1).** Agent hosts and the MCP services join the external network `qa-harness-p4` by alias. Host ports stay on `127.0.0.1`. Host networking is not used.
- **Reference forks for the agent hosts (never edited):** `Jayami123/openclaw` and `Jayami123/LibreChat` are reference copies. The harness uses only the pinned images above.
